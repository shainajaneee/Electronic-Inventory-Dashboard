# Electronic-Inventory-Dashboard
A PHP & MySQL web-based inventory system for managing products, stock levels, and suppliers with low-stock alerts.

## Features
- View all inventory items in a table
- Add, edit, and delete inventory items
- Track total items and total stock
- Low stock alert with highlighted rows
- Dropdowns for stock by item and low stock items
- Simple responsive dashboard with sidebar navigation

## Technologies Used
- PHP (with PDO for MySQL)
- MySQL / MariaDB
- HTML, CSS, JavaScript
